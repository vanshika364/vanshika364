# Vanshika Bajaj - Portfolio

A lightweight one-page portfolio for Vanshika Bajaj, focused on forward deployed engineering, machine learning, data science, and work across finance, manufacturing, and healthcare.

## Status

Private draft. The source is stored in the profile repository, but the website is not deployed or connected to GitHub Pages.

## Local preview

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm test
npm run lint
```

The portfolio intentionally does not include a resume download.
